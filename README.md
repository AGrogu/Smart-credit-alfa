# Умный кредитный кабинет предпринимателя

Рабочий демонстрационный MVP: кабинет бизнеса и кабинет банковского аналитика, разовый кредит и возобновляемая кредитная линия.

## Запуск

Нужны Docker Engine/Desktop и Docker Compose v2. Из корня проекта:

```bash
docker compose up --build
```

Открыть http://127.0.0.1:8080/#credit-cycle. Первая сборка требует сети для образов и зависимостей. PostgreSQL, заявки и документы сохраняются в именованном volume. Не удаляйте volume для обычного перезапуска.

## Демоучетные записи

Пароль всех учетных записей: `Demo2026!`.

| Логин | Доступ |
|---|---|
| `good@demo.local` | Предприниматель: бизнес A и D, выбор организации |
| `bank@demo.local` | Банковский аналитик |
| `bank2@demo.local` | Второй аналитик |
| `prepare@demo.local` | Подготовитель без права отправки/подписи |
| `admin@demo.local` | Демочасы и технические сценарии |
| `fix-a@demo.local` … `fix-l@demo.local` | 12 синтетических профилей |

Первый запуск создает пользователей и шаблоны. Для заполненных синтетических заявок доступен `scripts/prepare-v2-demo.py`: он обращается только к localhost и не сбрасывает данные; требуется Python с httpx из dev-зависимостей.

## Реализованные функции

- Серверные черновики, финансовая история и прогноз, документы и отдельные согласия.
- Разовый кредит: оценка платежеспособности, альтернативный срок/сумма, оффер, демоподпись, выдача и аннуитетный график.
- Возобновляемая линия: активация без выдачи, транши, календарная оценка возврата, ACT/365, частичное погашение и восстановление лимита.
- Категории A/B/C отдельно от решения, DSCR и стресс по периодам, ручное рассмотрение и уточнения.
- Версии и хеши условий, проверки полномочий, идемпотентность и защита конкурентных денежных операций.
- Общие денежные потоки организации учитываются один раз по всем договорам.
- Банковская очередь, назначение аналитика, публичные объяснения и закрытые внутренние заметки.
- Сохраняемые задания, демочасы, просрочка и история операций.

## Технологии

FastAPI, SQLAlchemy, Alembic, PostgreSQL 17.4; React, TypeScript, Vite. SQLite используется для автономных тестов. Старая версия доступна по `#dashboard` и `#queue`; новая кредитная политика работает в `#credit-cycle`.

## Проверка

На финальной версии прошли 127 тестов на SQLite и PostgreSQL, 14 браузерных сценариев Chromium, Ruff, TypeScript, ESLint и production build. Отдельно проверен фактический restart приложения и БД без потери договора, файла, сессии и незавершенного задания.

Команды и ограничения: [проверка](docs/V2_VERIFICATION.md). Для локального набора после установки зависимостей: `./scripts/check.sh`. Полная приемка всех AT/NFR и нагрузочные испытания не объявляются выполненными.

## Границы решения

Все компании, документы, деньги и операции синтетические. DEMO_POLICY_1: ставка 24%, комиссии 0, разовый кредит 300 тыс.–5 млн рублей на 6/12/18/24 месяца; линия 300 тыс.–3 млн на 12 месяцев, транши от 50 тыс. на 30/60/90 дней. Это демонстрационная политика из ТЗ, а не тарифы или внутренняя политика Альфа-Банка. Реальные реестры, БКИ, банковские переводы, юридическая подпись, OCR/LLM и промышленная эксплуатация не подключены.
